# Batch 10F — Classroom timing

**No timed rehearsal with human participants took place in this assignment.** The 90-minute plan below is a design target, not a measured result. Nothing in this report should be read as validated classroom timing.

## 1. Target plan (unchanged from the brief)

| Activity | Target (min) | Supported by the product |
|---|---:|---|
| Opening | 5 | Facilitator creates the session (path chosen at creation), teams join with codes, NexLearn introduction screen |
| Q1–Q3 | 18 | Three "fast" quarters: 6 min each, from the decision-screen pacing hint (Batch 10A) and the stage-clock "Fast quarter 6:00" preset (Batch 10E) |
| Q4 | 9 | "Major quarter 9:00" preset; destination commitment |
| Q4 signal review | 2 | "Looking back: which signals mattered?" opens automatically at Q4 results; Q3 panel in Class Discussion opens when every team has finished Q4 |
| Q5–Q8 | 36 | Four "major" quarters, 9 min each |
| Final debrief | 20 | "Final debrief 20:00" preset; Final debrief tab; board report |
| **Total** | **90** | |

## 2. What V3 adds to each quarter (estimated, not measured)

| Addition | Where | Expected time cost |
|---|---|---|
| Market path choice | Session setup (facilitator, before class) | None in class |
| Contract claim ("$X of your $30M budget"; "make room" button) | Q5 | Under 30 s. It replaces mental arithmetic the team previously had to do. |
| Recession stance (one required choice) | Q6 | About 30–60 s of discussion; the stance usually summarises a choice the team is already making |
| Financed expansion | Optional, in the CFO financing panel | 0 when unused (the default policy never uses it); 1–2 min when a team debates it |
| Saturation warning | Allocation screen | None. It shortens debate about over-funded buckets. |
| Path-specific briefings | Every quarter | Same length as path A (authored to the same word budget) |

**Net expected effect:** about +1–2 minutes over the eight quarters. That fits inside the 36-minute Q5–Q8 block only if teams keep to the 9-minute guide.

## 3. Automated walk-through durations (not classroom timing)

The browser tests drive the full classroom loop without discussion time, at machine speed.

| Run | Duration |
|---|---:|
| Path B, two teams, eight quarters for one team and four for the other (one refreshing at every phase on a phone), facilitator opening every quarter | 2.1 min |
| Batch 10E facilitator suite, two teams to Q8 | 1.3 min |
| Classroom suite, three teams Q1–Q8 | 1.8 min |

These durations show that the software adds no waiting: no step blocks on the server for more than a moment. **They say nothing about human discussion time.**

## 4. Recommendation before the first V3 class

Run one timed rehearsal with one or two teams of colleagues on the chosen path. Record:
- minutes per quarter (stage clock);
- Q6 stance discussion time;
- the Q4 review;
- the length of the debrief.

Adjust the stage-clock presets if Q5–Q8 exceed 9 minutes. Path C's deeper recession may lengthen the Q6 discussion.
